01

Research problem

The base paper DMRA-NMF mixes ordinary edges with triangle motifs using a weight α, but tunes that weight manually with ground-truth labels.

02

Research gap

Real networks are usually unlabelled. In that setting there is no principled, label-free way to choose α for a deep NMF model.

03

Proposed solution

Subsample the graph twice, cluster both copies, and measure partition agreement with Adjusted Mutual Information (AMI).

04

Main contribution

Select α* = argmax stability(α) without reading labels, then refit once on the full graph. The rule is independent of the base factorisation.

Methodology

How the method works

Four steps, from the raw adjacency matrix to the final community partition.

1

Build the triangle motif matrix

Each entry counts how many triangles an edge belongs to. Higher-order structure is useful because triangles are a strong signal of a community.

B = A ∘ (A · A)

A · A counts two-hop paths; the element-wise product keeps only paths that close a triangle. B is rescaled so max(B) = max(A).

2

Combine edges and motifs with α

α controls the trade-off: α = 0 uses only ordinary edges, α = 1 uses only motifs.

M(α) = (1 − α) A + α B

The same graph can therefore be viewed at different "orders" of structure. The right α depends on the dataset.

3

Factorise with deep NMF

A product of non-negative layers learns a community representation Ψ. Laplacian smoothness and a diagonal-dominance penalty keep communities coherent.

M ≈ Ψ W Ψᵀ ,   Ψ = H₁ H₂ … Hₚ
L = ‖M − ΨWΨᵀ‖² + λ·tr(ΨᵀLMΨ) + μ·‖W ∘ (1 − I)‖²

Node labels are read as argmaxk Ψ[i, k].

4

Choose α by perturbation stability

Remove 20% of edges twice, fit the model on each copy, and compare the two partitions with AMI. The most reproducible α is used on the full graph.

S(α) = AMI( C₁(α), C₂(α) ) ,   α* = argmaxα S(α)

AMI is adjusted for chance, so stable partitions are not rewarded merely for having many small clusters. No ground truth is used here.

Implementation scope. This is the symmetric, triangle-only, Adam/softplus simplification named DMRA-lite — not an exact reproduction of the asymmetric DMRA-NMF paper. The Experiments and Limitations sections state this explicitly.

Contribution

Alpha selection

How the motif weight is chosen without ever looking at labels.

What α means

α is the mixing weight between the adjacency matrix and the triangle motif matrix. Low α favours ordinary links; high α favours triangles.

Candidate values

{% for a in candidates %}α = {{ a }}{% else %} No candidates recorded{% endfor %}

Why it must be selected

The original paper sets α per dataset using labels. On an unlabelled network that is impossible, and a poor α can hide the community structure.

How perturbation and AMI work

Two independent 80%-edge subsamples are clustered. AMI compares the resulting partitions while correcting for agreement by chance; high AMI means the partition is reproducible under small changes to the graph.

Final selection

The α with the highest mean stability is selected. Exact ties are broken using full-graph modularity. The final model is then trained once with α*.

Scope

Research limitations

These limitations are stated openly in the project report and dashboard.

Model simplification

The implementation is a symmetric, triangle-only, Adam/softplus DMRA-lite model. It is not an exact reproduction of the original asymmetric DMRA-NMF paper; the novel selection rule is independent of that choice.

Assumptions

The number of communities k is assumed known — taken from genuine labels when present, otherwise estimated by modularity optimisation. Only undirected graphs and triangle motifs are supported.

Baselines and data

DMoN-lite optimises the modularity objective without a GNN encoder. Cora and Citeseer need torch-geometric; otherwise clearly marked synthetic stand-ins are used.

Reporting

The CP1 report planned degree-normalised matrices and Wilcoxon tests. The code uses the raw mixed matrix (suited to symmetric NMF), reports mean ± standard deviation, and leaves significance testing as future work.
